You're probably here because you've been trying really hard to solve a problem without getting to a solution. The user has had to report back that the issue still exists several times.

Take 10 steps back. Really think through what the source of the problem might be. Help the user help you: consider adding logs to the code and asking the user to take an action and/or report back if you can't see them yourself
